El abanico

47 ideas nuevas para el portfolio (30 de Codex y 18 mías; el menú de pausa se nos ocurrió a los dos) en diez familias, sin repetir las de la primera ronda. Las 24 más distintas llevan una imagen de referencia generada con ChatGPT: es un boceto de por dónde iría, no el diseño final. Pulsa una imagen para verla en grande.

Interfaz como mundo

FM / Buscar

La web es un lanzador tipo Spotlight/Raycast: escribes «juegos», «IA», «Odoo» y salen proyectos, CV o contacto al instante.

Codex 01

Menú de pausa

La web es el menú de pausa de un videojuego moderno: Misiones = proyectos, Estadísticas = habilidades, Créditos = experiencia.

Claude 2 + Codex 03

El tablero vivo de los agentes

La portada es el tablero de su equipo de agentes trabajando solo: tarjetas que pasan de En curso a Revisión a Publicado.

Un panel de aeropuerto de paletas: cada proyecto es un vuelo con su estado; pulsas uno y «embarcas» en la ficha.

  • Caza del dato Codex 14

  • Dos a la vez Codex 15
    Dos cursores autónomos intentan escribir en el mismo espacio y el jugador evita sus colisiones.
  • Flexómetro Codex 17

  • Texto con interruptores Codex 21

  • Oferta invertida Codex 23

  • Sin lorem ipsum Codex 24
    La portada parece un wireframe, pero todos sus supuestos rellenos son trabajo real y verificable.
  • Solo un número Codex 27
    Una cifra comprobable ocupa la portada y obliga al resto del caso a explicar exactamente qué significa.
  • La URL es la firma Codex 28
    Una dirección web descomunal hace visible que cada proyecto tiene un lugar propio al que volver.
  • La web que cabe Codex 29
    El visitante cambia el ancho de una demo y ve cómo el mismo producto sigue siendo utilizable.
  • El portfolio que se queda Codex 30
    Toda la selección profesional puede guardarse para leerla después sin conexión.
  • Diff de mi vida Claude 3
    La web es un pull request: su trayectoria como diff y un botón verde «Merge» para contactar.
  • Titular que se compila Claude 4
    Letras enormes que se construyen con el scroll, de esqueleto a letra rellena.
  • Tamagotchi de servidor Claude 12
    Una mascota que es su servidor: la cuidas con despliegues y copias, y cada acción explica algo real.
  • Una sola frase Claude 18
    Un color que cambia con la hora de Marbella y una frase enorme cuyas palabras abren proyectos.
